### Termux / Android support (arm64 + armv7)

- Releases now ship native Android (bionic) binaries — `9router-go-android-arm64` (CGO-free, part of `make cross` / `CROSS_TARGETS`) and `9router-go-android-armv7` — so the gateway runs under Termux on 64-bit and 32-bit ARM devices. The armv7 target is built outside the CGO-free matrix by `scripts/build-android-armv7.sh` (`make cross-android-armv7`) because Go's linker requires external linking (the NDK clang) for every android target except arm64; CI and the release workflow install NDK r27 for that one target and append its digest to `SHA256SUMS.txt`.
- Fixed two 32-bit compile failures the armv7 build exposed: `maxMetadataPriceCents` was formatted with `%d` as a bare `int` constant (overflows on 32-bit) and MiniMax's `expired_in` millisecond epoch was compared and converted through `int` (now an `int64` path via `positiveInt64`, clamped to `math.MaxInt32` for plain-seconds values).
- Android no longer falls back to "not supported" stubs for procfs/termios helpers: `/proc/<pid>/exe` (`internal/proc`), the tray socket-owner check (`internal/tray`) and the password prompt's termios handling (`internal/clientconfig`) now include `android` in their build tags (files renamed so the filename constraint cannot silently exclude them).
- The Gemini debug dumps write to `os.TempDir()` instead of a hardcoded `/tmp`, which does not exist on Android; Termux's `$TMPDIR` is honoured.
- The self-updater can now match the armv7 asset: `archAliases("arm")` returns the `armv7` family, and `matchReleaseAsset` never hands a 32-bit arm install the `arm64` asset ("arm" is a substring of "arm64"). Covered by `TestMatchReleaseAssetAndroidArm`.
- `install.sh` detects Termux (`TERMUX_VERSION` / `$PREFIX` / `uname -o`), downloads the Android asset and installs into `$PREFIX/bin` without sudo; armv7l/armv8l map to the armv7 asset. README gains a Termux/Android section (install, background/autostart notes, desktop-only features that stay off).
- Verified locally before pushing: `GOOS=android GOARCH=arm64` build (ELF aarch64 PIE, interpreter `/system/bin/linker64`), full `GOOS=linux GOARCH=arm GOARM=7 go build ./...`, the armv7 Android binary built with NDK r27 via `scripts/build-android-armv7.sh` (ELF 32-bit ARM PIE, interpreter `/system/bin/linker`), unit tests for every touched package, and a simulated Termux run of `install.sh` (asset + `$PREFIX/bin` selection). The CI `cross` job asserts both Android artifacts' architecture and bionic interpreter on every PR.
